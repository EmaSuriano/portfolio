A plain list of websites I keep coming back to. I'll add more as I find them.

## Github

- [Repo Remover](https://reporemover.xyz/) — Bulk-search, archive, or delete GitHub repos in the browser. The token never leaves your device.
- [Github Involves me](https://github.com/pulls/involves) - Official Github page that many not know that shows all the PRs where you need to take a look.

## SEO

- [Meta Tags](https://metatags.io/) — Preview how a page looks on Google, Facebook, X, LinkedIn, and Slack, then copy the meta HTML.
- [Is Agentic](https://is-agentic.com/) - Score how agentic your site is for LLM. Key in these crazy times ...
- [Ora](https://ora.ai/) - Like Is Agentic, but a bit more focused on Sass websites.

## Design

- [Shrink Me](https://shrinkme.app/) — Compress JPG, PNG, WebP, SVG, and PDF so sites and apps load faster.
- [Color Hunt](https://colorhunt.co/) — Browse hand-picked four-color palettes for design and art.
